# Video Work

Use for requested social, faceless, or product videos. This is project-fit and verification guidance, not another renderer workflow.

## Reuse The Brief

- Read the project's existing brief, `DESIGN.md`, visual-style notes, media, and approved decisions before asking design questions. Reuse the requested audience, duration, aspect ratio, brand, and voice.
- Ask only about unresolved choices that materially affect the result. Delegated routine choices do not require a new style interview.
- Use an available video specialist, such as Hyperframes, when it fits the task. Check installed CLI help/version against the relevant documentation; do not patch managed plugin cache files or copy newer commands blindly.
- Support factual claims with evidence. Use assets relevant to the actual product or subject, with usage rights appropriate to the requested distribution.

## Check The Render

- For Thai, inspect glyph shaping, font availability, wrapping, safe areas, subtitle timing, and readable text density in actual rendered frames.
- Preserve the approved voice and pronunciation settings. Valid audio metadata is not proof of correct Thai pronunciation; distinguish technical audio checks from listening.
- Check the rendered file's duration, resolution, aspect ratio, and decode success. Inspect meaningful timestamps, transitions, and start/end frames for missing assets, blank frames, clipped text, overlap, or unintended crop.
- Review motion and audio through playback when supported. If only frames or metadata were reviewed, state that limit; a successful render command alone does not prove output quality.
- Keep source, required assets, and reproduction settings available within the requested scope. Exporting a file does not authorize external publication.

Reference: [Hyperframes upstream](https://github.com/heygen-com/hyperframes). Verify the installed version and its documentation before selecting commands.

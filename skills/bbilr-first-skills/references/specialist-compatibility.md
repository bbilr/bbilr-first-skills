# Specialist Compatibility

These user-owned preferences supplement AGENTS.md and take precedence over conflicting third-party skill defaults. Host permissions and higher-priority instructions still apply.

- Respond in the user's requested language; for Thai conversations use Thai even when codex-market-skills requires Chinese. Preserve tickers, identifiers and source-language quotes where needed.
- Existing authorization covers routine steps necessary for the agreed task. Do not repeat a generic "Proceed?" or demand approval for each command solely because Turnstile Spin, Game Development Studio or another playbook says so. Ask for unresolved consequential choices, new scope, spending, external actions or irreversible changes not already authorized; never bypass tool approval controls.
- Use one workflow owner. For web UI use Impeccable; consult Stark only for a concrete platform/UX gap, not its general router plus a second full web workflow. Preserve approved design and palette.
- Unity Agent Workflows is disabled globally in the maintainer setup. Use Unity MCP and relevant Unity task skills; load the extra workflow only when explicitly requested or selected for a specific project's evidenced need. Never silently re-enable a plugin.
- Generative Media Skills (MuAPI) is disabled in the maintainer setup. Do not reinstall/upgrade its CLI per session or choose a paid provider just because the task mentions media. Re-enablement and provider use must stay within explicit authorization.
- Game Studio is for browser games; Game Development Studio is for its game-dev CLI workflows. Do not stack them for every game request or substitute Phaser for an existing Godot/Unity project.
- Financial-router selects the needed tool; tradingview-analysis supplies tool-specific instructions. Do not run two planning/approval passes or load every finance skill. Provider defaults do not establish live availability.
- RunComfy music, Cloudflare One/migrations and Sandbox SDK variants are task-specific. Select them only for the requested provider/product/version; do not migrate SDK versions or add services automatically.
- Task Observer remains explicit-review-only and proposal-only. Compatibility work does not enable background observation.

These are routing and instruction boundaries, not proof of runtime availability or guaranteed future model behavior. Do not edit managed plugin caches to enforce them; preserve this supplement when reviewing upstream updates.

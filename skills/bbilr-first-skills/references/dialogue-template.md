# Dialogue Planning Template

Use only for a requested branching-dialogue task. Fill the fields relevant to the game; omit the rest.

- Scene purpose and desired player outcome
- Speakers and entry conditions
- Nodes, choices and branch destinations
- Variables, initial values and state changes
- Runtime commands and quest links
- Exit, repeat-visit and unavailable-choice behavior
- Test cases covering reachable branches and state transitions

Use the project's actual dialogue engine and syntax. This is a template, not a separate workflow or a mandatory subagent handoff.
